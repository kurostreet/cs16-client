# Сервис Counter Zombie Mobile

Живёт на VDS владельца (kontrafps.ru): API для игры, бот владельца в Telegram, мировой список серверов.
Один процесс uvicorn на `127.0.0.1:8200`, Caddy снаружи. База — SQLite в `/var/lib/czm`.

## Что делает

- **Игроки:** `POST /api/v1/hello`. Игра шлёт свой секретный ключ (создаётся на телефоне), отпечаток устройства, ник, аватар, язык, версию.
  - В ответ: номер игрока, бан, номер последней новости, обновление.
  - Ключ и отпечаток хранятся только как хеш с «перцем» сервера.
- **Чат:** комнаты global, ru, en.
  - `GET /api/v1/chat/<комната>?after=N` — новые сообщения, удалённые владельцем, бан.
  - `POST /api/v1/chat/<комната>` — сообщение до 200 символов, не чаще раза в 3 секунды, повтор того же текста за минуту не проходит.
  - Мат заменяется на `***` (`czm/profanity.py`).
  - В комнате видны последние 100 сообщений, старше 7 дней удаляются.
- **Жалобы:** `POST /api/v1/report` на сообщение или аватар. Не больше 10 в час, одна жалоба на одно и то же раз в сутки.
  - Бот присылает владельцу текст (или аватар) и кнопки: бан на неделю / месяц / навсегда, удалить сообщение, не нарушение.
  - Бан — по игроку и по устройству. При бане за сообщение оно удаляется, за аватар — аватар сбрасывается.
- **Аватар игрока:** `POST /api/v1/avatar` (PNG/JPEG до 512 КБ) → `/avatars/<номер>.png`, 192 px. Без премодерации.
- **Новости:** `GET /api/v1/news?after=N`, пишутся командой бота `/news`.
- **Обновления:**
  - `GET /api/v1/update?code=N`;
  - APK лежит в `/var/lib/czm/apk`, отдаётся с `/dl/` (с докачкой);
  - выходит в игре только после `/release` в боте.
- **Мировой список серверов:** раз в 5 минут из Steam Web API (нужен ключ `CZM_STEAM_KEY`).
  - Пишется в формате мастер-списка движка;
  - отдаётся по обычному HTTP: `http://kontrafps.ru/server-list/v1/servers/cstrike`.

## Бот

Тот же бот, что был у видео-проекта. Telegram с сервера закрыт, Bot API идёт через ретранслятор владельца.
Команды: `/news`, `/delnews`, `/release`, `/ban`, `/unban`, `/bans`, `/stats`, `/help`. Отвечает только владельцам.

## Установка и обновление

На сервере от root:

    curl -fsSL https://raw.githubusercontent.com/kurostreet/cs16-client/<коммит>/server/czm/deploy/install.sh | bash -s <коммит>

- Код ставится в `/opt/czm/releases/<коммит>`, ссылка `/opt/czm/current`, окружение `/opt/czm/venv`.
- Настройки и секреты — `/etc/czm/env`: `CZM_BOT_TOKEN`, `CZM_BOT_API_URL`, `CZM_BOT_OWNER_IDS`, `CZM_PEPPER`, `CZM_STEAM_KEY`.
  - Первый раз бот берётся из `/etc/fva/env`, «перец» создаётся случайный.
  - Ключ Steam владелец вписывает сам.
- Служба `czm.service`, сайт Caddy — `deploy/czm.caddy` в `/etc/caddy/sites/`.

Новая сборка для обновления: APK кладётся на сервер, затем

    runuser -u czm -- bash -c 'set -a; . /etc/czm/env; cd /opt/czm/current; /opt/czm/venv/bin/python -m czm.cli add-release <apk> <версия> <код>'

и владелец выпускает её в боте `/release что нового`.
