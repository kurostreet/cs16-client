## Что сохранено

- `server/czm/czm/apkpatch.py`: черновик потокового создания патчей из одинаковых сжатых ZIP-записей.
- Формат: 8 байт `CZMPAT01`, длина JSON как uint32 big-endian, JSON-рецепт, блок новых байтов.
- Рецепт: `format`, `base_sha256`, `sha256`, `base_size`, `size`, `data_size`, `ops`.
- Операции: `[0, offset, length]` копируют исходный APK; `[1, offset, length]` копируют блок новых байтов. Смещения второго вида последовательны относительно начала бинарного блока.
- Заголовок и количество операций ограничены 2 МиБ и 50000; размер APK — 2 ГиБ.
- Проверка восстановления в SHA-256 без дополнительного полного APK на диске.
- Таблица `release_patches` и выбор подходящего патча по установленному versionCode в `hello` и `update`.
- Дополнительные поля API: `patch_format`, `patch_url`, `patch_size`, `patch_sha256`, `base_sha256`. Поля полного APK сохранены для совместимости.
- Черновая интеграция в `assemble.py`: до трёх прошлых APK, проверка каждого патча перед публикацией, ошибка патча оставляет полный APK доступным.
