- Выбор по установленному versionCode в `hello` и `update`; поля полного APK сохранены.
- Таблица `release_patches`, автоматическое хранение патчей вместе с целевыми выпусками, новый модуль включён в `deploy/install.sh`.
- 10 серверных проверок прошли: ZIP stored/deflated, изменённый порядок, подпись и комментарии, проверка байтов при одинаковом CRC, неверная база, повреждённые данные, границы, API, хранение и откат публикации.
- Проверка на настоящих APK на сервере: `1.35-293607e` → `1.35-65a8615`; полный APK 400490050 байт, патч 68069253 байта. Скопировано из базы 332457020 байт. Результат побайтно совпал с целевым SHA-256 и прошёл `apksigner verify`. Операция заняла 9,6 секунды, пик памяти Python 25912 КиБ. Это измерение конкретной пары, размер будущих обновлений зависит от изменений.
