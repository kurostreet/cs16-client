# План Counter Zombie Mobile 32 players

Дата начала: 10 октября 2026 года.
Репозиторий: https://github.com/kurostreet/cs16-client
Основа: https://github.com/Velaron/cs16-client
Исходный коммит: `c1604b609c553a6825278324f70b2ba54013fd41`.

## Что согласовано

- Взять исходники CS16Client за основу своей версии.
- Заменить оформление меню.
- Показывать в списке свои серверы.
- Сделать Android-приложение с постоянным меню управления установкой, обновлениями и запуском.
- Автоматизировать подготовку и распаковку игровых файлов.
- Вести работу в видимом владельцу репозитории GitHub.

## Состояние исходников

`main` содержит исходную версию автора с полной историей и лицензией.
Наши изменения начинаются в ветке `feature/mobile-launcher`.
ZIP с исходниками соответствует указанному коммиту, но не содержит содержимого подмодулей.
Для сборки нужен рекурсивный checkout зависимостей YaPB, mainui_cpp, ReGameDLL_CS и MiniUTL.

Xash3D FWGS и SDL добавлены как закреплённые исходники. Движок, клиент и игровые ресурсы
объединены в один APK. Отдельные Xash3D/CS16Client не нужны.
Полная сборка установлена и проверена на телефоне; отчёт — [STANDALONE_TEST_2026-10-10.md](STANDALONE_TEST_2026-10-10.md).
Параметры текущего проекта: Android 5.0+, compileSdk/targetSdk 36, NDK 28.2.13676358;
архитектуры `armeabi-v7a`, `arm64-v8a`, `x86`.

## Этапы

1. **Исходная основа.** Создать fork, сверить `main`, сохранить историю и зависимости.
2. **Контрольная сборка.** Собрать неизменённый Android-клиент и проверить запуск с Xash3D на телефоне.
3. **Единый APK — выполнено.** Движок и клиент работают внутри одного пакета.
   По последнему решению владельца установка отдельных APK не используется.
4. **Меню и серверы.** Сделать своё оформление, список серверов, ник и запуск выбранного сервера.
5. **Подготовка данных.** Проверять свободное место, структуру архива и целостность файлов;
   распаковывать в каталог, доступный выбранной архитектуре приложения.
6. **Обновления.** Добавить проверку версий, докачку, восстановление файлов и сохранение настроек игрока.
7. **Проверка пользователя.** Пройти установку на чистом телефоне, первый запуск, обрыв загрузки,
   обновление и подключение к каждому своему серверу.

Выполнены исходная основа, контрольные сборки, собственное название/иконка/главное меню,
интеграция движка и автоматическая подготовка встроенных данных. Проверены первый и повторный
запуск, локальная карта и сервер на 32 слота с ботами. Свои серверы, зомби-режим, обновления
и остальные проверки — дальнейшая работа.

## Данные для следующего этапа

- Название и логотип уже утверждены; остальные изменения оформления согласуем отдельно.
- Актуальные адреса, порты и названия серверов, которые нужно показывать.
- Решение о поддерживаемых устройствах и минимальной версии Android.
- Подтверждённый источник и права на распространяемые игровые материалы.

## Работа с файлами и лицензиями

Список полученных архивов и APK, размеры и SHA-256 находятся в `INPUT_FILES.json`.
Хеши определяют конкретные присланные файлы; они не подтверждают подпись APK или права на содержимое.
Игровые данные пользователя подготавливаются отдельно от исходников.
Для материалов Valve базовый сценарий — импорт файлов из законно приобретённой копии;
общедоступная загрузка возможна для материалов с разрешением на распространение.
Лицензии и сведения об исходных авторах сохраняются.

Команды для обычной среды разработки:

```sh
git clone --recurse-submodules https://github.com/kurostreet/cs16-client.git
cd cs16-client
git switch feature/mobile-launcher
```
