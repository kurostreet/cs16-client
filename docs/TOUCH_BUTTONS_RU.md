# Кнопки на экране и редактор раскладки

Утверждено владельцем 11 октября 2026 года.

## Что сделано

- Новый набор иконок: тёмный полупрозрачный круг и белый значок. У «Огня» красное кольцо.
- Три схемы кнопок:
  - **Классика**;
  - **Шутер** — большой левый огонь, оружие внизу по центру;
  - **Минимум**.
  У каждой схемы свои сохранённые изменения.
- Свой редактор раскладки вместо движкового.
- Каталог действий для новых кнопок: 65 действий в 7 группах.
- Кнопка «Ещё» показывает и прячет редкие кнопки. Они называются `more_*`.

## Редактор

Откуда открывается:
- в меню: «Управление» → «Кнопки на экране» → «Изменить»;
- в матче: «Ещё» → шестерёнка.

Фон редактора:
- в меню — скриншот владельца из матча (`gfx/czm/ui/editor_bg.png`);
- в матче — сама игра, без затемнения.

**Верхняя панель:**
- схемы 1 | 2 | 3;
- «+ Добавить»;
- «Скрытые» — показывает скрытые кнопки бледными, с крестиком;
- «Сброс» — стандартная раскладка текущей схемы;
- «Сохранить»;
- «Выход» — спрашивает, сохранить ли изменения;
- стрелка сворачивает панель. Вернуть её: язычок «Панель» сверху.

**Кнопки на экране:**
- тап выбирает кнопку;
- палец тащит её;
- подписи под кнопками видны только в редакторе.

**Панель выбранной кнопки** (появляется с той стороны экрана, где кнопки нет):
- название и команда;
- ползунок «Размер» (50–250 %);
- ползунок «Видимость»;
- «Скрыть» / «Показать»;
- «Иконка» — любая из 66;
- «Действие» — другое действие из каталога;
- «Удалить».

**Группы каталога:**

| Группа | Действия |
|---|---|
| Бой | огонь, прицел, перезарядка, использовать, оружие 1–4, прошлое / следующее / предыдущее, выбросить, фонарик, ночное видение, спрей |
| Движение | прыжок, присесть, присесть вкл/выкл, прыжок с приседом, тихий шаг, автобег, вперёд/назад/влево/вправо (пока держишь) |
| Покупка | меню покупки, патроны к основному и пистолету, броня с каской, автозакупка, повторить закупку |
| Общение | чат, командный чат, голос, рация и три её меню, счёт |
| Сервер | `/zpmenu`, `/menu`, `/unstuck`, `/rs`, `rtv`, `/top15`, `/rank`, `/vip`, `timeleft`, `nextmap` |
| Меню | «Ещё», цифры меню, кнопки 1–0, закрыть меню, сменить команду, скриншот, настроить кнопки |
| Своё | сообщение в чат (`say …`) и своя команда консоли |

**Как работают особые действия:**
- «Автобег» — тап включает бег вперёд, второй тап выключает (алиас `czm_autorun`);
- «Вперёд (держать)» — `+forward`, бежит, пока палец на кнопке.

## Файлы

**Как хранятся схемы:**
- стандартные схемы: `touch_presets/czm_scheme1..3.cfg`;
- изменения игрока: `touch_profiles/czm_scheme1..3.cfg`;
- выбранная схема: `czm_touch_scheme`.

**Первый запуск этой версии** (`czm_touch_version` < 1): старая раскладка заменяется схемой 1.

**Как сохраняется:**
- через `touch_exportconfig`;
- `touch_writeconfig` движка пишет файл только после своего редактора, поэтому не используется.

**Скрытые кнопки:** у них флаги `1 | 64`. Флаг 64 сохраняет кнопку скрытой, даже если «Ещё» показало её в матче.

**Иконки:**
- лежат в `gfx/czm/touch/*.png`, 256×256;
- значки с game-icons.net (CC BY 3.0, авторы Lorc, Delapouite, Skoll, sbed);
- часть нарисована своя: огонь, присесть, стрелки, «Ещё», «Застрял»;
- авторы указаны в `gfx/czm/touch/CREDITS.txt` и в окне «Об игре».

**Алиасы:** `userconfig.d/czm_touch.cfg` — `czm_autorun`, `+czm_duckjump`, `czm_more`.

**Генератор:** `scripts/make_czm_touch.py`.
- Делает иконки, три схемы и фон редактора.
- Запуск:
  ```
  python3 scripts/make_czm_touch.py --game-icons <папка icons из game-icons> --screenshot <скриншот>
  ```

**Код:** `czm/menu/CzmTouch.cpp`.
