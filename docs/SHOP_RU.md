# Магазин и меню сервера карточками

Утверждено владельцем 11 октября 2026 года.
- Колесо и сетка — оба, игрок выбирает в настройках.
- Автооткрытие магазина по галочке, по умолчанию выключено.
- Меню сервера — карточками.

## Магазин

Открывается кнопкой «Покупка» (команда `buy`).
- Сервер присылает меню закупки, клиент передаёт его библиотеке меню.
- Вместо стокового меню открывается наш экран (`czm/menu/CzmShop.cpp`): окно клиента поверх игры.

**Что на экране:**
- сверху: «МАГАЗИН», команда (Террористы / Спецназ), деньги, крестик;
- слева категории: пистолеты, дробовики, пистолеты-пулемёты, винтовки, пулемёты, снаряжение;
- снизу быстрые кнопки: «Повторить закупку» (`rebuy`), «Автозакупка» (`autobuy`), «Броня + шлем» (`vesthelm`), «Патроны» (`primammo; secammo`), «Гранаты» (`hegren; flash; sgren`);
- что не по карману — бледное, цена красная;
- что уже есть — отметка (колесо) или «ЕСТЬ» (сетка);
- после покупки сверху надпись «Куплено: …»; не хватает денег — «Не хватает $ …».

**Колесо** (`czm_shop 1`, по умолчанию), как в CS:GO:
- оружие категории по секторам, справа карточка: силуэт, цена, урон, патроны, подвижность, кнопка «Купить»;
- палец на секторе подсвечивает его и показывает карточку, отпустил на секторе — покупка;
- увёл палец в центр — отмена.

**Сетка** (`czm_shop 2`), как в Standoff 2 / CS2: крупные карточки, тап — покупка.

**Классика** (`_vgui_menus 0`): текстовое меню сервера, оно показывается карточками (ниже).

**Как устроено:**
- **Цены и списки** — стандартные CS 1.6, у каждой команды свои.
  Если плагин на сервере меняет цены, экран этого не знает, но спишет сервер свою цену.
- **Покупка** — обычные команды CS 1.6: `ak47`, `m4a1`, `vesthelm` и так далее.
- **Силуэты** — из картинок самой игры (`gfx/vgui/*.tga`):
  - при открытии магазина делаются белыми с той же прозрачностью и обрезаются по краям;
  - отдаются движку как TGA из памяти, отдельных файлов нет.
- **Картинки колеса** — `gfx/czm/shop/wheelN.png` (колесо из N секторов) и `wheelN_I.png` (подсветка сектора I).
  - N от 1 до 8.
  - Делает их `scripts/make_czm_shop.py`.
- **Деньги, команда, оружие, броня** — клиент пишет их в `czm_buy_state` (`деньги команда биты_оружия броня шлем жив`), меню читает.
- **Закрывается:**
  - крестиком или «Назад»;
  - сам, когда кончилось время закупки или игрок вышел из зоны (сервер присылает BuyClose);
  - при смерти.
- **Автооткрытие** (`czm_shop_auto 1`): когда в раунде впервые появляется значок зоны закупки, клиент сам отправляет `buy`. Один раз за раунд.

## Меню сервера карточками

Касается меню плагинов (`/zpmenu`, VIP, голосования) и классического меню закупки.
- Вместо мелкого текста и кнопок с цифрами — панель слева.
- Заголовок меню и крупные карточки с номером.
- Недоступные пункты серые.

**Как устроено:**
- **Клиент** (`cl_dll/menu.cpp`) кладёт меню в `czm_menu`: «номер маски_пунктов», перевод строки, текст.
  Свой текст и кнопки-цифры при этом не показывает.
- **Библиотека меню** (`czm/menu/CzmServerMenu.cpp`):
  - разбирает текст: цветовые коды `\y \r \w \d`, `\R` уводит остаток вправо;
  - строки «1. Пункт» становятся карточками;
  - рисует их поверх игры (вызов из `UI_UpdateMenu`).
- **Тапы:** над каждой карточкой невидимая клиентская кнопка `_menu_czmN` с командой `slotN`.
  - Остальной экран работает, ходить и смотреть можно.
  - Палец на карточке не запускает ходьбу — это правка движка из шага с кнопками.
- **Порядок отрисовки:** движок теперь рисует кнопки управления до библиотеки меню (`cl_view.c`), чтобы карточки были сверху.
- **Выключить:** `czm_menu_cards 0` — вернётся старое текстовое меню.

## Настройки (вкладка «Игра»)

- «Магазин»: Колесо | Сетка | Классика.
- «Автооткрытие магазина» — выключено по умолчанию.
- «Меню сервера карточками» — включено по умолчанию.
