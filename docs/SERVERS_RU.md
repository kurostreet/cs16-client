# Список серверов

Утверждено владельцем 11 октября 2026 года: вернуть список серверов CS16Client и сделать ему наш вид.
Открывается кнопкой «Серверы» внизу главного экрана.

## Что видит игрок

- **Шапка:** «Назад», «СЕРВЕРЫ», поиск, «Обновить», «+» (добавить сервер по IP).
- **Поиск** — по названию, карте и IP, сразу при наборе. Регистр не важен, русские буквы тоже, «ё» = «е».
- **Вкладки:**
  - Все — серверы с мастер-списка;
  - Избранное — со счётчиком;
  - История — последние 20 серверов, где игрок играл, свежие сверху.
- **Фильтры** (запоминаются): Не пустые (без ботов), Есть места, Без пароля, Зомби (карты zm_, ze_, zp_… или «zombie»/«зомби» в названии).
- **Сортировка** (запоминается): по игрокам, по пингу, по названию. В «Истории» — по времени.
- Над списком: сколько серверов и живых игроков.
- **Строка сервера:**
  - картинка карты со значком режима (ZM, ZE, DE, AIM…);
  - название и замок, если с паролем;
  - своих серверов у проекта пока нет, поэтому меток «НАШ» нет (решение владельца 11.10: чужие серверы нашими не называем);
  - карта и число ботов;
  - игроки «12/32» с полоской заполненности, пинг с цветной точкой;
  - звёздочка — добавить в избранное или убрать.
- **Нажатие** на строку выбирает сервер, двойное — сразу подключает.
- **Карточка выбранного сервера справа:**
  - картинка карты, название в две строки, игроки, пинг, пароль, IP;
  - список игроков с фрагами, на широком экране в две колонки;
  - кнопки «В избранное» и «ИГРАТЬ».
  - Каждые 4 секунды сервер опрашивается заново.
- **Пароль:** если сервер закрыт, перед подключением спрашивается пароль.
- **Добавить по IP:** поле с клавиатурой и кнопкой «Вставить» из буфера; порт по умолчанию 27015.
  Сервер попадает в избранное.
- После игры, начатой из списка, и после неудачного подключения игрок возвращается в список.

## Картинки карт

1. Наши превью зомби-карт: `gfx/czm/maps/<карта>.png` (из проекта kontra, без отметки «MOD»).
2. Стандартные карты: обзорная карта из данных игры `overviews/<карта>.bmp`.
   - Меню обрезает её по самой карте и уменьшает в памяти до 352×160.
   - Фон обзорной карты (ярко-зелёный в CS 1.6) заменяется тёмно-синим.
   - В APK ничего не добавляется. Одна карта за кадр, чтобы не было рывков.
3. Остальные — картинка режима: зомби, побег, классика, прочее (`gfx/czm/maps/_*.png`).

Картинки делает `scripts/make_czm_maps.py <папка kontra>`. Это 256-цветные PNG, вместе около 0,8 МБ.

## Откуда данные

Так же, как в стоковом списке CS16Client (`menus/ServerBrowser.cpp`):

- **«Все»:** команда `internetservers`.
  - Движок берёт мастер-списки. Сейчас это `http://xash.su/server-list/v1/servers/cstrike`, около 23 серверов.
  - Старый мастер Valve (hl1master / hl2master) больше не работает.
  - Потом движок опрашивает каждый сервер.
  - Список старше минуты обновляется при открытии экрана.
- **Избранное и история:** стоковые файлы `favorite_servers.lst` и `history_servers.lst`, формат «адрес протокол»;
  каждый сервер опрашивается командой `ui_queryserver`.
- **Ответы:** приходят через `UI_AddServerToList`.
  - Только серверы этой игры (`gamedir` cstrike).
  - Сервер, который не ответил 8 секунд, во «Все» скрывается, в избранном показывается «Сервер не отвечает».
- **Игроки:** запрос NetAPI players к выбранному серверу.
- **Пинг:**
  - движок запоминает время каждого запроса информации — мастер-список, `ui_queryserver`, `czm_queryserver`;
  - по первому ответу присылает меню `\czmping\N`.
  - Новый запрос к тому же серверу, пока прежний в пути (до 2 секунд), время не сбрасывает.
    Иначе ответ на старый запрос приходил сразу после нового и показывал «0 мс».
  - Таблица запросов — хеш на 4096 адресов: мастер-список опрашивает тысячи серверов разом.
- **Challenge:** если сервер отвечает на запрос информации challenge, движок один раз повторяет запрос с ним.
  Раньше такие серверы в стоковый список не попадали.
- **Боты:** движок передаёт меню их число (ключ `bots`).

## Весь мир

Мастер-сервер Valve закрыт, весь мир CS 1.6 сейчас знает только Steam Web API (`IGameServersService/GetServerList`, appid 10).
Ему нужен ключ. План:
- наш VDS раз в несколько минут забирает список по ключу владельца;
- отдаёт его в формате мастер-списка;
- в игру добавляется `addmasterstatic <адрес VDS>`.

Ключ владелец вводит на VDS сам.
