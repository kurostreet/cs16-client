# Новое главное меню

Утверждено владельцем 11 октября 2026 года. Шаг 1 из 4 (план — в проектном документе).

## Что видит игрок

- **Шапка:**
  - аватар и ник; нажатие открывает настройку профиля;
  - колокольчик со счётчиком непрочитанных (сообщения придут с kontrafps.ru на шаге 3);
  - переключатель RU | EN. Первый раз язык берётся из языка телефона.
- **Плитки режимов справа:** ZOMBIE ATTACK, ZOMBIE ESCAPE, ZOMBIE BOSS.
  - На плитке: карта, онлайн «N/M в игре» и пинг (зелёный < 80 мс, жёлтый < 150 мс, красный — выше).
  - Опрос серверов каждые 6 секунд, пока открыт главный экран.
  - Нажатие подключает сразу к серверу.
- **Нижние разделы:**
  - Профиль;
  - Управление (сенсор, кнопки, гироскоп);
  - Настройки;
  - Об игре (версия, лицензии).
- **Кнопка «Назад»** на главном экране спрашивает «Выйти из игры?».
- **Пауза в игре** (кнопка «Назад»): маленькое окно «Продолжить · Настройки · Выйти в меню».
- **Убрано:**
  - публичный список серверов, поиск и фильтры, избранное;
  - LAN, создание сервера, сохранения, тренировка с ботами;
  - большое меню паузы.
- После неудачного подключения игрок возвращается на главный экран с причиной ошибки.

Скрытый вход для отладки: «Об игре» → 5 нажатий по строке «Версия» открывают консоль.

## Где что лежит

| Часть | Где |
|---|---|
| Главный экран и пауза | `czm/menu/CzmMain.cpp` |
| Общие функции, тексты RU/EN, серверы, загрузка | `czm/menu/CzmMenu.cpp` |
| Текстуры плиток, иконки, кнопки | `3rdparty/cs16client-extras/gfx/czm/ui/` (создаёт `scripts/make_czm_ui.py`) |
| Правки стокового меню | `scripts/brand_mainui.py` |

Временный список серверов — таблица `s_servers` в `czm/menu/CzmMenu.cpp`.
Сейчас там чужие рабочие серверы для проверки. На шаге 3 список будет приходить с kontrafps.ru,
а последний скачанный останется запасным.

Данные для плиток даёт команда движка `czm_queryserver <адрес>`:
- шлёт обычный запрос информации: часть серверов молча отбрасывает запрос NetAPI с challenge -1;
- шлёт запрос NetAPI для серверов, которые сначала отвечают challenge;
- пинг считается по первому ответу на запрос, потому что многие серверы не отвечают на пакет пинга.

Ответы приходят в меню через `UI_AddServerToList`.
